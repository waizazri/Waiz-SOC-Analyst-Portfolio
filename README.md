# SOC Analyst Portfolio

Hands-on cybersecurity projects focused on security log analysis, network traffic investigation, and threat hunting. This portfolio documents practical investigations, the tools and queries used, findings, and supporting screenshots.

## Projects

| # | Project | Focus | Tools |
|---|---|---|---|
| 01 | [DNS Log Analysis](01-dns-log-analysis/) | Review DNS activity and identify potentially suspicious domain lookups | Splunk |
| 02 | [Windows Security Log Analysis](02-windows-security-log-analysis/) | Investigate Windows security events and authentication activity | Splunk |
| 03 | [Network Traffic Analysis with Wireshark](03-network-traffic-analysis-wireshark/) | Inspect network traffic and investigate protocol-level indicators | Wireshark |
| 04 | [Windows Privilege Escalation Investigation](04-windows-privilege-escalation-investigation/) | Investigate Windows endpoint telemetry and Sysmon events | Windows logs, Sysmon |
| 05 | [Coinhive Cryptojacking Threat Hunt](05-coinhive-threat-hunt/) | Hunt BOTS v3 DNS telemetry for Coinhive-related domains and identify the host of interest | Splunk Enterprise, SPL, BOTS v3 |

## Skills Demonstrated

- Security log analysis and event investigation
- DNS and network traffic analysis
- Splunk Search Processing Language (SPL)
- Windows endpoint and security event investigation
- Threat hunting based on hypotheses and telemetry
- Evidence documentation and mapping findings to MITRE ATT&CK

## Certifications

- CompTIA Security+

## Approach

Each project aims to document the investigation objective, methodology, queries or filters, observed results, supporting evidence, and limitations. Findings are described carefully: an indicator or suspicious pattern is not treated as proof of compromise without corroborating evidence.

## Disclaimer

These projects are for learning and portfolio demonstration using lab or public training data. They do not represent investigations of real production incidents.
